# Luna Sight — Lunar Landing Site Navigator (Team Ginkgo Orbit)

NASA Space Apps Challenge 2026 · Seoul · Challenge: *Lunar Landing Site Navigator*

> Live demo: (GitHub Pages link — added once the first build is deployed)

Compare lunar landing sites and dates: at that site and time, can a lander see the Sun (power) and the Earth (direct-to-Earth link)?

## Status
Work in progress during the hackathon (Nov 14–15, 2026).

## Repository layout
- `web/` — static web app (deployed to GitHub Pages)
- `pipeline/` — Python data processing
- `data/DATASETS.md` — every data source, URL, license and citation
- `docs/SI_USAGE.md` — Super Intelligence (AI) usage log
