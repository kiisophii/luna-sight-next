## Scope and limits

- Same inputs as the producer (LOLA LDEM_64/16, `ephem.bin`, contract definitions): this checks that the published map follows from them, not the physical accuracy of the DEM (that is the PGDA validation).
- The PNG comparison tests the published 8-bit product exactly; it cannot show differences smaller than the file's own rounding. The 0.1 %p test on floats covers only the cells with published floats.
- PNG rows whose footprint straddles 75° S (row 1877) are excluded because cells north of 75° S were not recomputed.

Reproduce (about 2.5 h on 4 cores, resumable per row):

    LDEM_DIR=<dir with LDEM_64.IMG/LBL, LDEM_16.IMG/LBL> GMAPS_XCHECK_WORK=<scratch> \
      python pipeline/crosscheck_gmaps_polar_dongju.py run
    python pipeline/crosscheck_gmaps_polar_dongju.py compare   # -> docs/crosscheck_gmaps_polar_dongju.{json,md}
