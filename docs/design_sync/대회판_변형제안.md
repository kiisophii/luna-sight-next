# 대회판 변형 제안 (기본판에는 넣지 않음. 만들지는 수아가 정함)

기본판은 채이님 사본과 똑같이 만든다. 아래는 사본에 없지만 대회판에 이미 있었거나, 넣으면 낫다고 보는 것들이다.

| 제안 | 이유 | 채이님 사본과의 차이 |
|---|---|---|
| 미션 조건에 'Sun + Earth together' 칸 | 해와 지구가 함께 보이는 시간으로 후보를 거를 수 있다. 대회판에 이미 동작하던 조건 | 사본은 4칸(일조·지구·경사·최장 어둠)이고 이 조건은 숨겨서 'any'로 둔다 |
| 미션 조건에 'Ground link'(지상국 교신) 칸 | 여주 KDSA·DSN이 달을 볼 수 있는 시간으로 거를 수 있다(한국 연결 요소) | 사본은 이 칸을 'Coming soon'으로 두었다가 16:37판에서 뺐다 |
| 맞는 곳 수 'Matching 33 / 33' 표시 | 조건을 바꿨을 때 몇 곳이 남는지 바로 보인다 | 사본은 목록 머리줄 'All 36'으로만 보인다 |
| 확대 + / − 버튼 | 마우스만 쓰는 사용자가 확대하기 쉽다 | 사본에는 없다(핀치·Ctrl+휠만) |
| 비교 번호 고정(#n 유지) | 후보를 빼도 남은 후보의 번호와 색이 바뀌지 않아 그래프를 읽기 쉽다 | 사본은 01부터 다시 매긴다 |
| Site check '준비 중' 칩 빼기 | 데이터가 없는 분석을 보여 주면 미완성으로 보일 수 있다 | 사본은 흐린 칩 4개 + "Coming soon" |
| 미니맵 Esc로 닫기 | 키보드 사용자가 펼친 미니맵을 닫기 쉽다 | 사본은 Esc로 닫히지 않는다 |
| 390 모바일 배치(세로로 쌓기) | 사본은 390에서 데스크톱 배치가 잘려 보인다. 휴대폰으로 열 수도 있다 | 사본에는 모바일 배치가 없다(요청서는 1440·1280·1024만 다룸) |
| 부제 "Lunar Landing Site Navigator" | 제출 화면에서 챌린지 이름이 바로 보인다 | 사본에는 없다 |
| 정렬 글자 한 줄 말줄임 | 사본은 1440에서 정렬 글자가 두 줄로 꺾이고 1280에서 잘린다(사본의 버그로 보임) | 사본은 꺾임 |
| 상세 비교 값 아래 보조 줄("29.5 of 29.5 d") | 퍼센트가 며칠인지 바로 보인다 | 사본은 값만 |
