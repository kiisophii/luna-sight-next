## 1. 가장 중요한 점: 시간이 아니라 **스크롤로 움직인다**

- 가만히 두면 **로켓은 32초 동안 출발점에 그대로 서 있다**(1440에서 x936 y228). 반복 재생도 자동 재생도 없다.
- About 아래쪽 본문(히어로 아래 스크롤 칸)을 내리면 장면이 앞으로 가고, 올리면 **거꾸로 돌아간다.** 스크롤 위치가 곧 장면 시간이다.
  - 진행도 p = 본문 스크롤 위치 ÷ (본문 전체 높이 − 보이는 높이)
  - 장면은 p 0에서 0.85 사이에서 끝난다. **0.85부터 끝까지는 착륙한 마지막 장면에 멈춰 있다.**
  - 0–0.85를 같은 길이 네 구간(각 0.2125)으로 나눈다: ① 발사와 가속 → ② 순항 → ③ 뒤집기와 감속 하강 → ④ 착륙과 먼지(착륙 뒤 약 1.4초 분량).
- 스크롤을 갑자기 옮기면 장면이 바로 점프하지 않는다. **매 화면마다 남은 거리의 12%씩 따라가는** 부드러운 추적이다. 60 fps에서 약 0.4초 안에 95%까지 따라붙는다. 1 ms 이내로 가까워지면 그 위치에 맞춘다.
- **동작 줄이기(prefers-reduced-motion: reduce)** 설정이면 처음부터 착륙한 마지막 장면을 보여 주고 따라가는 효과도 없다.
- About이 숨겨져 있으면 아무것도 계산하지 않는다. 열 때마다 본문 맨 위(p = 0, 출발 장면)에서 시작한다.

- **경로:** 지구 위의 발사점에서 달 아래쪽 가장자리까지 오른쪽 위로 가는, 아주 조금 휘는 곧은 선이다. 기울기는 가로 46 대 세로 119로, 수직에서 약 21° 오른쪽.
- **가속:** p 0–0.10은 제자리에서 불꽃만 켜진다(점화). 0.10–0.25에 천천히 출발해 빨라진다(ease-in).

## 4. 크기와 배치 (1440 · 1280 · 390)

About 화면은 위아래 세 줄이다: 고정 머리줄 / 히어로 띠 / 본문 스크롤. **히어로 띠 : 본문 = 3 : 7.** 띠의 최소 높이는 200px이다.

- 그림 위에 겹치는 것(히어로 띠의 장식 층):
  - 왼쪽부터 어두워지는 가로 그라데이션: 0%에서 rgba(5,7,10,.85), 28%에서 .45, 그 뒤 투명. 왼쪽 글자를 읽기 쉽게 하는 용도다.
  - 아래쪽 9% 높이가 페이지 배경색으로 녹아드는 세로 그라데이션.
- 왼쪽 글자 덩어리(제목, 설명, 버튼)는 그림 위에 겹친다. 최대 폭 440, 왼쪽 여백 4vw.
- 스크롤에 따라 바뀌는 것은 **장면 시간뿐**이다. 히어로 띠의 위치와 크기는 고정이다(본문만 스크롤된다).

4. 효과:
