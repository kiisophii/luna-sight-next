# Detail Z4 author report

Author-side implementation and tests only. The required independent team-member verification is **PENDING**.

## Product and method

Generated `web/data/detail/history.json`: all 33 catalogue queries, three nearest other landers per query, and the 18-mission Task R input pool. The query ID is excluded, not merely a matching coordinate. Future/target sites cannot be candidates. Historical status is evaluated at 2026-11-15, not at the query mission's landing date.

Great-circle distance uses R = 1,737,400 m. Bearings are initial clockwise angles from true north. Undefined coincident, antipodal and polar-origin bearings carry explicit statuses and null angles. Ties use unrounded distance followed by mission ID. The small 33 x 18 calculation uses one CPU and the Python standard library; CUDA is not warranted.

Coordinates, dates, coordinate/time source URLs and cautionary notes are preserved from `docs/task_r_landings.csv`, including Blue Ghost 1 at 18.562 N, 61.81 E. Official mission context links are separately recorded in `docs/detail_z4_sources.json`. Existing NASA/CNSA source retrieval hashes are reused from `docs/task_r_manifest.json`; additional CNSA, ISRO, JAXA and NASA pages were checked via official web results or opened pages. The Chang'e-5 official search result was available, while its full-page open timed out; this is recorded explicitly. The builder has no network dependency.

Historical proximity is not evidence of usable infrastructure, accessibility or traversable route length. The 18 records are the task-defined sample, not an exhaustive inventory of lunar landers. Stored decimal precision does not improve source coordinate accuracy.
