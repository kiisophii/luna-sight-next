- 33 sites for time/history; 16 south-polar sites for PSR. Existing core.js visibility rules and 43,824 hourly cells, [i,i+1).

- PSR classification/no-data/projection must be read from original metadata; report lower bound if search finds none, never infer ice. Distances on R=1737400 m; bearings true-north initial bearings.
- History excludes self and future/target locations; three nearest actual landers from task_r_landings.csv, official sources included.
- CPU budget initially <=6 concurrent computational threads total, BLAS threads=1 per worker. Existing preview servers untouched. Raw data and resumable caches on existing D-backed ignored paths. GPU only when benchmark/input size justifies it.
- No new messages to teammates; PR carries handoff. Independent team verification remains pending even after another AI session checks the author's outputs.

- Whole-window/all-visible/all-dark runs and start/end clipping without counting false transitions.

- PSR nodata vs illuminated class; search-window completeness; pixel centre vs boundary and stereographic scale.
- Self/excluded history IDs, poles/date line and coincident-point bearing undefined.
- Resume stale input signatures, portable source hashes, no partial final index publication.
