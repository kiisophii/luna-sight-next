# Task Y implementation plan

User requested Y after north terrain verification. North verification passed and PR #74 is open. This branch starts at main 673e250; Y is a separate producer product, not a change to existing horizons, metrics or UI.

## Accepted scope and definitions

- All 16 south-polar sites: finest available original PGDA 5, 10, then 20 m, with full valid 1 km neighborhood plus derivative padding. Fetch small native windows via the existing validated Range reader; source caches stay on D. Record unavailable finer products and actual selected resolution. Do not treat transport failures as missing coverage.
- Landing slope: least-squares height plane over 3 x 3 samples spaced by native resolution and centred on the exact site coordinate (bilinear original DEM). Pixel-centre span is 2 pixels, footprint 3 pixels; report both. Distribution slopes use native pixel-centred 3 x 3 fits. Correct polar projection scale and reference-radius/height ground scale; no resampling claim of finer information.
- Geodesic radius masks at 100/500/1000 m on R=1737400 m. Slope median/p95/max across native valid centres. Flat fractions are horizontal-area weighted using stereographic scale, thresholds 8/15 degrees configurable and explicitly reference values, not safe-landing criteria.
- Roughness: RMS vertical DEM-height residual from a local best-fit plane. A nominal 50 m ground-width square includes native sample centres within +/-25 m of each window centre. Record actual odd sample count and sample-centre span (20 m DEM necessarily has sparse samples). Summarize median/p95 within 500 m. It is DEM-derived roughness, not boulder detection or raw LOLA-spot roughness.
- All 33 sites: copy the existing rounded 250 m-box slope at relay candidate e=n=0 with exact file hash and candidate index. The 17 non-polar products contain only this coarse comparison, clearly labelled SLDEM2015 59 m / LDEM_64. Do not invent high-resolution distributions there.
- Atomic per-site outputs and input/code/config signatures for resume; English schema/docs, source and SI logs. No index.html or existing production data edits.
