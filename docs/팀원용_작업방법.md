# 팀원용 작업 방법 (AI 세팅 → 작업 → GitHub에 올리기)

| 사람 | 도구 | 읽을 장 |
|---|---|---|
| 김동주, 김수아 | Claude Code | **D** (A–C는 필요 없음) |
| 김민철, 오채이, 정소윤 (Plus), 성지용 (Pro) | Codex | **F** |

세 도구 모두 저장소를 clone하면 `CLAUDE.md`(Claude Code)·`AGENTS.md`(Codex)에 들어 있는 **공통 브리프 + 기록 규칙을 자동으로 읽어요.** 그래서 따로 붙여 넣을 건 **본인 이름·카드 번호 + 카드의 첫 프롬프트**뿐이에요.

> 메뉴 이름은 화면 버전에 따라 조금 다를 수 있어요. 막히면 단톡에 화면 캡처!

## A. Claude 프로젝트 만들기 (처음 한 번)
1. claude.ai 왼쪽 메뉴에서 **Projects(프로젝트)** → **Create project(새 프로젝트)**.
2. 이름: `Ginkgo Orbit - 04` → 만들기.
3. 프로젝트 화면 오른쪽의 **Instructions(지침)** 칸을 눌러 아래 두 개를 순서대로 붙여 넣고 저장:
   - `공통_브리프.md`의 ```(코드 블록)``` 안 영어 전체
   - `SI_기록_통일설정.md` 2장의 ``` 안 설정 문장 → `[이름 영문]`, `[역할 번호 + 역할명]`을 본인 것으로 바꾸기 (예: `Minchul Kim`, `1 Ephemeris`)
4. (선택) 같은 화면의 **Files / Project knowledge**에 `1단계_분배.md`를 올려 두면 AI가 카드 내용을 참고할 수 있어요.

## B. 작업하기
1. 프로젝트 안에서 **새 채팅** → `1단계_분배.md`에서 **본인 카드의 '첫 프롬프트'만** 붙여 넣기.
2. AI가 만든 코드·파일을 받아서 내 컴퓨터에 저장(파일 이름은 카드의 '고칠 파일' 그대로).
3. 검증은 같은 프로젝트의 **다른 채팅**에 카드의 '검증 프롬프트'를 넣어서.
4. AI 답 끝의 `SI-LOG` 한 줄은 복사해 두기(PR 설명에 붙임). 마지막 두 칸(어떻게 확인했나)은 본인이 채우기.

## C. GitHub에 올리기 (웹으로, git 몰라도 됨)
1. **초대 수락**: GitHub 알림이나 메일의 초대 → Accept. 저장소 페이지로 이동.
2. **내 브랜치 만들기**: 저장소 첫 화면 왼쪽 위 `main` 버튼 클릭 → 새 이름 입력(`단계-일-이름`, 예 `s1-ephem-minchul`) → **Create branch: … from main**.
3. **그 브랜치가 선택된 상태인지 확인**(왼쪽 위에 내 브랜치 이름).
4. 파일 올리기:
   - 새 파일: **Add file → Create new file** → 이름 칸에 `pipeline/ephem.py`처럼 폴더까지 입력(`/`를 치면 폴더가 생김) → 코드 붙여 넣기
   - 파일 여러 개: **Add file → Upload files** → 끌어다 놓기(폴더째 끌면 폴더 구조 유지)
   - 아래 **Commit changes**: "Commit directly to the `내 브랜치` branch" 선택 → 커밋
5. **PR 만들기**: 위에 뜨는 노란 **Compare & pull request** 버튼(안 보이면 **Pull requests → New pull request** → base `main`, compare `내 브랜치`).
   - 제목: `[카드 1] Ephemeris 2026–2030`
   - 설명: 한 일 / 확인한 방법(검증 결과 숫자) / SI-LOG 줄 / 출처(DATASETS.md에 적은 것)
   - **Create pull request**. **합치기(Merge)는 누르지 않기** — 수아가 확인 후 합침.
6. 고칠 게 생기면 **같은 브랜치에 다시 올리면** PR에 자동으로 붙어요.

## D. (선택) Claude Code를 쓸 수 있는 사람
- 터미널에서 `npm install -g @anthropic-ai/claude-code` → `claude` 실행 → Claude 계정으로 로그인(Pro 포함).
- `git clone <저장소 주소>` → `cd` → `git checkout -b s1-ephem-minchul` → `claude` 실행 후 카드의 첫 프롬프트 입력.
- 저장소의 `CLAUDE.md`(브리프+기록 규칙)를 자동으로 읽어요. 끝나면 "commit and push this branch"라고 시키고, PR은 C-5처럼 웹에서 만들기.

## F. Codex (김민철·오채이·정소윤·성지용)
1. Codex에 GitHub 계정 연결 → 저장소 `kiisophii/lunar-landing-site-navigator` 선택. 로컬에서 Codex CLI를 쓰면 `git clone` 후 그 폴더에서 실행.
2. 첫 메시지: `I am <이름 영문>, card <번호>. Create branch s1-<일>-<이름>.` + 카드의 **첫 프롬프트**.
3. 끝나면 Codex가 만든 변경을 **그 브랜치로 PR** 만들기(Codex의 PR 만들기 버튼 또는 `git push` 후 웹에서 PR). **main에 합치지 않기.**
4. Codex가 답 끝에 붙인 SI-LOG 줄을 PR 설명에 붙이고, '확인한 방법' 칸은 본인이 채우기.
5. 검증 프롬프트는 **새 작업(다른 세션)**으로 돌리기.

## E. 지켜 주세요
- `main`에 직접 올리지 않기, `web/index.html`은 수아만 고치기.
- 큰 원본 데이터(지형 TIF, 커널 .bsp 등)는 올리지 않기(`.gitignore`에 막혀 있음). 가공된 작은 파일만.
- 데이터를 쓰는 순간 `data/DATASETS.md`에 출처 한 줄.
- 숫자는 오늘 계산하고 검증한 것만.
